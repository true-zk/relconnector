# v2 当前情况与材料导航

## v1 与 v2 的区别

v1 是基于单进程的数据准备优化版本，通过节点去重、跨批次窗口、缓存复用和进程内线程流水线减少重复读取与编码。实际训练进一步暴露出 assemble（特征读取、编码与批次组装）的供给瓶颈：即使减少重复工作，数据准备仍可能跟不上 GPU 消费。v2 因此升级为多进程架构，将采样、assemble 和训练拆分为独立的执行阶段，分别由采样进程、组装进程池和训练主进程承担，通过有界队列连接并重叠执行。这里的单进程不等于单线程，多进程也不改变邻居采样与模型训练的算法语义。

快照时间：2026-09-27 15:48（北京时间）。依据“汇总 v2 各数据集耗时”会话、项目报告及本地实验记录整理。原会话仍在工作，本页不是后续实验的自动更新视图。

## 1. 当前结论

v2 已完成十任务的既定矩阵运行，并完成 Event、F1、Trial 补测、瓶颈复盘、汇报材料及论文背景/方法初稿。当前处于继续做局部优化、准备统一评测的阶段，尚未完成最终代码下的十库同条件正式对照。

## 2. 名称与主线

| 名称 | 定位 |
| --- | --- |
| Batch | 全量加载、编码后训练的参照，说明速度与内存权衡 |
| Vanilla | 基础按需读取与组装 |
| v1 | 单进程优化版本：节点去重、跨批窗口、文本复用等 |
| v2 | 采样、组装、训练多进程流水线，并降低初始化、缓存访问与数据准备成本 |

论文主线：关系学习需要跨表信息 → 全量物化受到内存容量约束 → 按批加载使数据准备成为瓶颈 → 按阶段减少重复工作、提高供给能力。四阶段为离线初始化、seed 采样、特征编码与 batch 组装、GPU 训练。项目主要优化前三阶段的数据路径，不把 GPU 模型算法改进算作贡献。

不要把采样阶段的请求去重、窗口合并写成新的邻居采样算法；不要把显式缓存配置或待实现的成本模型写成已经自动学习的策略。

### 当前选定 v2 成绩

均为两轮端到端，包含相应运行中发生的准备工作；不是纯 GPU 训练时间。

| --- | ---: | ---: | ---: | --- |
| Amazon | 14,699.63 | 1.484 | 1.89× | 文本与持久化缓存；部分热缓存，worker 诊断缺失 |
| Arxiv | 981.64 | 0.470 | 5.82× | 并行组装、编码路径及已有文本向量复用共同贡献 |

| HM | 1,760.13 | 0.118 | 1.98× | 请求行投影、本地编码缓存减少共享通信 |

## 4. 五类瓶颈，而不是十套孤立故事

| 负载特征 | 代表 | 已有处理 | 下一步 |
| --- | --- | --- | --- |
| 长文本、工作集大 | Arxiv、Amazon、Stack | 并行组装、直接编码路径、适用时持久化向量 | 批量键查询、分片读取、固定冷热快照 |
| 复用高但命中贵 | Salt、HM、Trial | 本地槽位索引、批量读取、请求行投影、本地缓存配置 | 减少复制与RPC；固定总预算验证缓存位置 |
| 读取与持续特征准备重 | Ratebeer、Avito | 多进程供给与训练重叠 | 测查询成本与读取放大，再选稀疏/块读取 |
| 宽表冷初始化重 | Event | 预算分组读列、精确partition、向量化、初始化复用 | 图拓扑构建仍约270秒 |
| 短任务固定开销高 | F1 | 通用路径、避免不必要的磁盘缓存 | 少worker或单进程选择仍待验证 |

这些类型可以重叠，机制解释不等于每项都已有独立消融实验。

## 5. 容易误读的结论

1. **Event**：冷初始化独立测量为2164.00→606.01秒，即3.57×。38.77秒是热初始化训练运行；图上49.83×含缓存状态和轮数摊销差异。60.05秒是更早一次热复测，三者不矛盾。
2. **Trial**：656.95→371.80秒是后续复测，包含热缓存，不能全部归因于代码改动。
3. **Ratebeer**：v1在4小时超时；v2运行约4小时17分、完成2×10,000批。不能声称同一预算下只有v2完成完整任务。
4. **RSS**：v2仅主进程，不含采样、组装和manager。旧PPT中“RSS下降27.5%”“Batch/v2为9.18倍”只能解释为记录值的比较，不能用于整体内存优势结论。
5. **平均数**：旧汇总页使用数据集等权，汇总报告的1.798×等值按实际batch折算再汇总；分母和权重不同，不能混为一个“平均提升”。Vanilla耗时比较仅双方完成的5项。
6. **Batch内存估算**：用户后来明确选择历史实测口径。估算文件作为容量分析附录保留，不替代RSS实测，也不与实测混入图表。
7. **代码与证据**：工作区存在大量未提交改动，源会话仍在实验。已有测试报告不等于当前所有改动都已统一验收。
